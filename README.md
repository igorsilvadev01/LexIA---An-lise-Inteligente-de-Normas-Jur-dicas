# LexIA---An-lise-Inteligente-de-Normas-Jur-dicas
Plataforma de ingestão, busca híbrida e extração estruturada de informações em documentos jurídicos, desenvolvida com Python, FastAPI, React e TypeScript. Utiliza BM25, busca vetorial, RRF e LLMs opcionais, com avaliação baseada em métricas e golden set.
